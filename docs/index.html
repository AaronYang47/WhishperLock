AES-256-GCM Encryption

Messages are encrypted using the AES-256-GCM authenticated encryption algorithm via Apple's CryptoKit framework. This provides both confidentiality (nobody can read the message) and authenticity (any tampering is detected).

AES-256-GCM CryptoKit 256-bit key
⏱️
Self-Destruct Messages

Optional self-destructing messages are encrypted with the same AES-256-GCM pipeline, wrapped in a time-limited payload. Once the timer expires, the message is permanently removed from the device. The server never stores the decrypted content.

Time-Limited Client-Side
🛡️
Authenticated Encryption

GCM mode provides built-in authentication tags. Every message includes a cryptographic signature that verifies the ciphertext has not been modified in transit. Any alteration — even a single bit — causes decryption to fail immediately.

Key Management

Deterministic room-based key derivation

Each chat room has a unique 256-bit encryption key derived from the room ID. Both participants derive the same key independently — no key exchange over the network.

Key Derivation Process

👤
User A
↔
SHA-256(roomId)
Deterministic derivation
↔
👤
User B

Both users independently compute the same symmetric key using:

  1. The room ID is converted to UTF-8 bytes
  2. SHA-256 hash produces a 256-bit digest
  3. The hash becomes the AES-256 symmetric key
  4. Key is stored in the iOS Keychain (kSecAttrAccessibleWhenUnlockedThisDeviceOnly)

No key is ever transmitted over the network. Both parties derive identical keys from the shared room identifier, ensuring seamless end-to-end encryption without any key exchange protocol.

Zero Data Policy

What the server never sees

WhishperLock's server acts as a blind relay. It stores and forwards encrypted payloads without any ability to decrypt them. Call data is not stored at all.

💬

Message Content

The database stores only Base64-encoded ciphertext. The server has no access to the encryption key and cannot read your messages.

🔊

Voice Call Audio

Call audio is never stored in any database. Packets are forwarded in real-time and discarded immediately. No recordings. No logs.

🔐

Encryption Keys

Keys are derived on-device and stored exclusively in the iOS Keychain. The server never receives or stores any encryption key material.
